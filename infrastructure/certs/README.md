# infrastructure/certs

`extra-ca.pem` (git-ignored) is generated by `scripts/bootstrap`. It holds the root
certificate(s) the host sees when it connects to `pypi.org`, `files.pythonhosted.org` and
`registry.npmjs.org`.

Why: TLS-inspecting antivirus (on the reference PC, Norton Web/Mail Shield) or corporate
proxies re-sign HTTPS traffic with a local root CA. Windows trusts that root, but
containers don't, so `uv`/`pnpm` downloads inside `docker build` fail with `UnknownIssuer`.

How it is used: it is passed to `docker build` as a BuildKit **secret** (`build_extra_ca`)
and only trusted for the duration of the dependency-download steps. It is **never copied
into an image**. On machines without interception it contains a public root CA, which is
harmless. An empty file is fine.

Alternative: exclude Docker Desktop / WSL traffic from your antivirus's HTTPS scanning, then
empty this file.
