# infrastructure/secrets

Generated by `scripts/bootstrap.ps1` (or `bootstrap.sh`). Everything here except this README is git-ignored.

| File | Used by |
|------|---------|
| `postgres_password` | Postgres superuser (`postgres`), for admin and migrations only |
| `database_password` | Application role `nocsoc_app` (no superuser, no BYPASSRLS, RLS enforced) |
| `auth_database_password` | Identity role `nocsoc_auth` (BYPASSRLS, identity tables only) |
| `valkey_password` | Valkey `requirepass` |
| `master_key` | Envelope-encryption master key (32 bytes hex) for secrets at rest, e.g. TOTP seeds |
| `dev-users.json` | Written by `scripts/dev seed`: seeded users' passwords and TOTP secrets (mock data) |

These secrets are **dev-grade** (threat model T19). Use mock data only. OpenBao/KMS is mandatory before any real credential is stored (P8 gate).
