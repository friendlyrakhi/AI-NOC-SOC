# ADR-0013: Git conventions

- Status: accepted
- Date: 2026-11-16
- Decision ID: D13 (docs/10-decisions-for-approval.md)

## Context
The repo had no commits on `master`, and the configured main branch is `main`.

## Decision
Branch `main`; conventional commits; one commit or PR per phase slice.

## Alternatives considered
Keep `master`.
