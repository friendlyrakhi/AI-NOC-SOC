# ADR-0015: Phase order: AI before automation

- Status: accepted
- Date: 2026-11-16
- Decision ID: D15 (docs/10-decisions-for-approval.md)

## Context
AI proposals feed the approval flow.

## Decision
P4 (AI) precedes P5 (automation).

## Alternatives considered
Swap them.

## Consequences
Swapping is cheap if priorities change.
